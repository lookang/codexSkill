# Editing in HyperFrames (HTML + GSAP -> MP4)

The edit is a single HyperFrames composition generated by Python, so timing is computed from the narration and
any line can be re-voiced and rebuilt. Templates: `templates/hyperframes-edit/` (a complete, working Part-2 build).

## Folder layout (beside the raw footage)

```text
<footage folder>/
  screen_<id>.mp4  camera_<id>.mp4          # raw, never modified
  <Name>.mp4  <Name>.srt  <Name>_thumbnail.png  <Name>_youtube_kit.md
  hf/                                        # HyperFrames project
    index.html  hyperframes.json  package.json  assets/{screen.mp4, fonts/, *.png}
  promo_build/                               # rebuild scripts + README
    narration.py tts.py build.py soundtrack.py audio.py master.py deliver.py sync_check.py vis_scan.py
    tts/ (wav + words.json)   work/ (plan.json, mix.wav, video_master.mp4, refs.json, hl_*.json, contact sheets)
```

Initialise `hf/` with `npx hyperframes init` (or copy `hyperframes.json`/`package.json` from a previous project).
Load the `hyperframes`, `hyperframes-core` and `hyperframes-animation` skills when available.

## Build steps

```text
python tts.py                  # Kokoro WAVs + tts/words.json (cached per cue)
python build.py                # -> ../hf/index.html + work/plan.json + work/hl_list.json
python vis_scan.py             # when highlight boxes changed: when is each target visible in the source?
python build.py                # retimes footage so targets are on screen while their boxes show
python sync_check.py           # verify every box against the footage (DROP/TRIM report)
python build.py
python soundtrack.py           # narration EQ/comp + synthesized music bed + SFX + ducking -> work/mix.wav (-16 LUFS)
cd ../hf && npx hyperframes@0.8.91 snapshot --at t1,t2,... --no-end --describe false    # preview stills
HF_VIDEO_COVERAGE_THRESHOLD=0 npx hyperframes@0.8.91 render -o ../promo_build/work/video_master.mp4 -q high --video-frame-format png
ffmpeg -y -i work/video_master.mp4 -i work/mix.wav -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 320k -ar 48000 -shortest -movflags +faststart ../<Name>.mp4
python deliver.py              # SRT, YouTube kit, thumbnail
```

Render time is roughly real time (a 14 min video takes 15-18 min). Run it in the background and verify the output
file's modified time and duration afterwards.

## How `build.py` is organised

- `SCENES` list. Each scene is either
  - `kind="foot"` with `beats=[(cue, src_in, src_out), ...]`: each beat lasts as long as its narration (+gap/tail)
    and the footage between `src_in` and `src_out` is retimed to fit (rate clamped to [0.25, 3]); or
  - `kind="gfx"` (built with `G(id, [cues])`): a full-screen motion-graphics scene.
- Overlay lists on a foot scene, all timed by **anchors**: `w(cue, word, n)` (the n-th occurrence of a word),
  `("src", seconds)` (a source time), a float (scene-local seconds) or `("end",)`.
  - `cams`: camera moves `(anchor, rect_in_source_px, tween_s)`; `FULL` / `PAGE` / `MODAL` presets.
  - `hl`: highlight boxes `(a0, a1, x, y, w, h, label)` with an animated pointer gliding to each.
  - `cards`: formula/explanation cards; `stamps`: big tilted words with shake + flash; `banners`; `counts`
    (prediction countdown on footage); `chapter` tag shown for the first 4.5 s of the scene; `sfx`.
- `gfx_html` / `gfx_js` define the graphics scenes (title, pain points, calculations, physics diagrams, predict,
  tips, end card). Animate on narration words with `W(cue, word, n)`.
- HyperFrames rules learned: `<video>` clips must not sit inside a timed ancestor (use an untimed `#stage > #cam`
  wrapper and show/hide by GSAP); use `immediateRender:false` on fromTo tweens of shared elements; inline-block
  caption spans need margins (spaces collapse); playback rates below ~0.15 starve the frame capture.
- Fonts: bundle the display/body fonts in `hf/assets/fonts`. Dark navy background with soft blobs; yellow `#ffd21f`
  accents; full-frame footage.

## Diagrams must be correct and complete

Draw concept diagrams inside a viewBox big enough for every state (e.g. a force arrow doubled in length must still
fit). Show each state the narration names: F appears; F disappears when I = 0; a 2F arrow when current doubles;
dot -> cross and the force flips when the current reverses. Check stills at each of those words.

## Audio (`soundtrack.py`, `audio.py`, `master.py`)

Synth bed (E minor, 120 BPM) with a riser into the title "drop", a calm breakdown under the teaching tips, SFX
(pop, hit, boom, ding, buzz, whoosh, tick, shimmer) from the plan, music ducked ~7 dB under speech, mastered to
-16 LUFS / -1.5 dBTP. Update the two scene ids it references (`drop` scene and `calm` range) for each new video.
